# Credits

## Dino and development

The project author created and edited Dino in Aseprite and supplied the Dino voice recording. The editable current animation is included in `Artwork/Dino.aseprite`. The game and its asset pipeline were developed with OpenAI Codex assistance, including gameplay code, scene assembly, tests, generated prototype artwork and audio preparation. Additional animation and UI polishing was done with Claude. These tools and sources are disclosed as part of the project's development history.

## Metal Slug media in the Windows build

The complete Windows build contains original Metal Slug sprites, backgrounds, sound effects, voices and music belonging to SNK/Nazca/Playmore. These files are excluded from the Unity source distribution. This prototype is not an official SNK game; the repository does not claim ownership of, or grant a redistribution license for, that media.
